# واژه‌نامه‌ی نمادنو (لحن مشتری)

هدف: هر جمله‌ای که مشتری (کاربر اپ، بازدیدکننده‌ی سایت، مدیر سازمان در پنل سازمان، و تیم بهره‌بردار وقتی با مشتری حرف می‌زند) می‌بیند، حس اطمینان و مالکیت بدهد، نه محدودیت.
واژه‌ی «قفل» و نماد قفل حس محرومیت می‌دهد؛ دارایی رزروشده هنوز مال کاربر است، سود می‌گیرد و در زمان مشخص آزاد می‌شود.

> فقط متن نمایشی عوض می‌شود. نام فیلدها و مقدارهای API (`locks`، `locked`، `lockType`، `vesting`، `collateral`، …) و نام متغیرها در کد **تغییر نمی‌کنند** (قرارداد با تیم بک‌اند).

## واژه‌های اصلی

| مفهوم | قبلاً | حالا |
|---|---|---|
| بخش غیرقابل برداشت دارایی (چتر کلی) | قفل، قفل‌شده | **رزرو**، **رزروشده** |
| بخش قابل برداشت | آزاد | **آزاد** (بدون تغییر) |
| دو عدد کنار نوار | آزاد X · قفل Y | آزاد X · **رزرو** Y |
| همه آزاد | بدون قفل | **همه آزاد** |
| شمارش | ۳ قفل فعال | **۳ رزرو فعال** |
| رویداد | قفل شد / قفل می‌شود | **رزرو شد / رزرو می‌شود** |
| رویداد آزاد شدن | آزادسازی، آزاد شد | بدون تغییر (مثبت است) |
| باقی‌مانده | قفل باقی‌مانده | **رزرو باقی‌مانده** |
| نماد چتر کلی | آیکن قفل | **ساعت شنی** (`HOURGLASS` در `src/lib/locks.ts`) |

## پنج نوع رزرو (`LOCK_META` در `src/lib/locks.ts`)

| نوع (API) | برچسب کامل | برچسب کوتاه | نماد |
|---|---|---|---|
| `vesting` | **پس‌انداز سازمانی** (قبلاً قفل زمانی سازمان) | **پس‌انداز** (قبلاً قفل زمانی) | جوانه |
| `collateral` | **پشتوانه‌ی وام و اعتبار** (قبلاً وثیقه اعتبار و وام) | **پشتوانه** (قبلاً وثیقه) | سپر |
| `installment` | **پشتوانه‌ی خرید اقساطی** | اقساطی | تقویم |
| `milestone` | **دریافت مرحله‌ای** (قبلاً آزادسازی مرحله‌ای) | مرحله‌ای | پرچم |
| `legal` | مسدودی قانونی (بدون تغییر — موضوع حقوقی، باید صریح بماند) | مسدودی | قفل |
| `none` (سیاست بسته) | **آزاد** (قبلاً بدون قفل) | **آزاد** | تیک |

## واژه‌های مرتبط

| قبلاً | حالا | نکته |
|---|---|---|
| وثیقه، وثیقه‌گذاری | **پشتوانه** | «وام با پشتوانه‌ی دارایی»، «نسبت پشتوانه»، «پشتوانه‌ی کارت» |
| قفل وثیقه | **رزرو پشتوانه** | |
| سیاست قفل (بسته / قرارداد)، نوع قفل بسته | **شیوه‌ی دریافت** | «شیوه‌های دریافت مجاز در قرارداد»؛ گزینه‌ها: آزاد، پس‌انداز سازمانی، دریافت مرحله‌ای |
| قفل زمانی، قفل زمانی سازمان | **پس‌انداز**، **پس‌انداز سازمانی** | «پس‌انداز تا ۱۵ دی» به‌جای «قفل تا ۱۵ دی» |
| آزادسازی مرحله‌ای | **دریافت مرحله‌ای** | «مرحله‌ی ۲ دریافت شد» |
| مسدودسازی کارت (موقت) | **توقف موقت کارت** | «رفع مسدودی» ← **فعال‌سازی دوباره** |
| مسدود دائم کارت | **ابطال کارت** | «کارت باطل شد» |
| مرحله‌ی قفل در KYC | **در انتظار** | |
| نیاز به اصلاح، رد مرحله‌ی قرارداد | **بازپس‌گیری** (اقدام سازمان) · **بازپس گرفته شد** (وضعیت) | سازمان تصمیم می‌گیرد مرحله پرداخت نشود: سهم مرحله از دارایی کارمند برداشته می‌شود و به سازمان برمی‌گردد. فقط در پنل سازمان به‌عنوان اقدام؛ برای کارمند آرام و همراه توضیح سازمان: «سهم مرحله‌ی ۳ «…» بازپس گرفته شد» (بدون رنگ هشدار و علامت تعجب) |
| آزادسازی خودکار مرحله | **خودکار در سررسید** · «این مرحله در ۲۰ دی خودکار آزاد می‌شود» | مرحله‌ای که «نیاز به تأیید» ندارد |
| ورود قفل می‌شود | **ورود موقتاً متوقف می‌شود** | |

## لحن

- کوتاه، مطمئن، آرام؛ بدون هشدار اغراق‌آمیز و علامت تعجب.
- از نگاه مالکیت بنویس: «این بخش برای شما رزرو شده و ۱۵ دی آزاد می‌شود»، نه «این بخش قفل است و نمی‌توانید برداشت کنید».
- محدودیت را با زمان یا شرط آزاد شدن همراه کن: «رزرو تا تسویه‌ی وام»، «آزاد در ۱۵ دی».
- رنگ: نوار رزرو هاشورخورده‌ی خاکستری می‌ماند (نه قرمز)؛ قرمز فقط برای خطا و مسدودی قانونی.
