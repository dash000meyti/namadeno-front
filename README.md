# نمادنو — Namadno Web

فرانت‌اند کامل نمادنو روی **Next.js 15 (App Router) + React 19 + MUI 7 (RTL)** با **بک‌اند ماک (MSW)**. همهٔ صفحه‌ها و جریان‌ها بدون بک‌اند واقعی کار می‌کنند؛ برای اتصال به بک‌اند فقط آدرس API عوض می‌شود.

| بخش | مسیر | صفحه‌ها |
|---|---|---|
| سایت عمومی | `/` | لندینگ، وبلاگ، درباره، سازمان‌ها، سوالات، تماس، امنیت، فرصت‌های شغلی، قوانین، حریم خصوصی، `/map` (نقشهٔ همهٔ صفحه‌ها)، `/design-system` |
| اپ کارمند (وب‌اپ موبایل) | `/app` | ۳۶ صفحهٔ طراحی: ورود/ثبت‌نام، دارایی‌ها، دریافتی‌ها، صندوق‌ها، خرید و فروش، واریز/برداشت، تاریخچه، اعتبار، وام، کارت، خرید اقساطی، احراز هویت، پشتیبانی |
| پنل سازمانی | `/org` | ۱۵ صفحه: داشبورد، کارکنان، بسته‌ها (ویزارد ارسال)، تسهیلات، درخواست‌ها، گزارش‌ها، قرارداد |
| کنسول بهره‌بردار | `/op` | ۱۵ صفحه: نمای کلی، سازمان‌ها، کاربران، صندوق‌ها، محصولات، قوانین، درخواست‌ها، ریسک، گزارش‌ها، تنظیمات |

## اجرا

نیازمندی: Node.js 20 یا بالاتر.

```bash
npm install        # msw فایل public/mockServiceWorker.js را خودکار می‌سازد
npm run dev        # http://localhost:3000
```

اگر `public/mockServiceWorker.js` ساخته نشد: `npm run msw:init`.

ورود نمایشی:
- اپ: هر شماره موبایل معتبر، کد تأیید **۱۲۳۴۵** (کاربر: سارا محمدی، هلدینگ آرمان)
- پنل سازمان و بهره‌بردار: هر ایمیل و رمز
- هر صفحه مستقیم هم باز می‌شود (بدون ورود، با هویت نمایشی همان بخش)

داده‌های نمایشی در مرورگر ذخیره می‌شوند؛ برای بازگشت به حالت اولیه: «حساب من ← بازنشانی داده‌های نمایشی» در اپ یا `POST /api/v1/_mock/reset`.

جریان کامل برای امتحان: پنل سازمان ← ارسال بسته برای سارا محمدی ← اپ ← دریافتی‌ها ← تأیید و تخصیص ← دارایی‌ها و تاریخچه به‌روز می‌شوند. تأیید مرحلهٔ قرارداد مرحله‌ای در پنل سازمان، بخش قفل‌شدهٔ صندوق طلای کاربر را آزاد می‌کند. مسدودی قانونی در کنسول بهره‌بردار روی دارایی کاربر دیده می‌شود. خرید و فروش صندوق به احراز هویت سطح ۳ و سرویس‌های اعتباری به سطح ۲ نیاز دارند (در `/app/kyc`).

## اتصال به بک‌اند واقعی

1. قرارداد API در [`docs/API.md`](docs/API.md) و انواع در `src/types/domain.ts` است.
2. در `.env.local`:
   ```
   NEXT_PUBLIC_API_MOCKING=disabled
   NEXT_PUBLIC_API_BASE_URL=https://api.example.com/api/v1
   ```
3. همهٔ درخواست‌ها از `src/api/client.ts` می‌گذرند (توکن Bearer، خطای `ApiError`). هوک‌ها در `src/api/*.ts` هستند و صفحه‌ها مستقیماً به آن‌ها وابسته‌اند؛ تغییری در صفحه‌ها لازم نیست.
4. منطق کسب‌وکار ماک (`src/mocks/handlers`) مرجع رفتار مورد انتظار است: آزاد = کل − قفل‌ها؛ برداشت/فروش/وثیقه فقط از بخش آزاد؛ تبدیل فقط ریال ⇄ صندوق؛ سقف وام ۴۰٪ دارایی آزاد؛ پنج نوع قفل.
5. پس از اتصال کامل، پوشهٔ `src/mocks` و `msw` قابل حذف‌اند.

## ساختار

```
src/app/(site)        سایت عمومی
src/app/app           اپ کارمند (قاب موبایل)
src/app/org           پنل سازمانی  — (auth)/login و (panel)/… با PanelShell
src/app/op            کنسول بهره‌بردار
src/api               کلاینت و هوک‌های React Query
src/mocks             MSW: db.ts، seed/، handlers/
src/components        ui/ (Icon، LockBar، Sheet، Toast)، app/، panel/، org/، op/، site/
src/lib               format.ts (اعداد و تاریخ شمسی)، routes.ts، locks.ts، clock.ts
src/styles            tokens.css (توکن‌های Namadno UI)، base/app/org/op/site.css
src/theme             تم MUI، RTL، حالت روشن/تیره
docs                  API.md، IMPLEMENTATION-GUIDE.md
```

راهنمای پیاده‌سازی و نگاشت فایل‌های طراحی به مسیرها: [`docs/IMPLEMENTATION-GUIDE.md`](docs/IMPLEMENTATION-GUIDE.md).

## نکته‌ها

- زمان دادهٔ ماک ثابت است (۱۵ آبان ۱۴۰۵، `src/lib/clock.ts`) تا تاریخ‌های نمونه معنا داشته باشند؛ با بک‌اند واقعی ساعت واقعی استفاده می‌شود.
- فونت IRANSansX تجاری است؛ پیش از انتشار عمومی مجوز استفادهٔ وب بررسی شود. فایل‌ها در `public/fonts`.
- متن صفحات قوانین و حریم خصوصی نمونه است و پیش از انتشار باید بازبینی حقوقی شود.
- `npm run typecheck` و `npm run lint` برای بررسی کد.
